# Sample data

Everything in this directory is **synthetic**. The names, organisations, email
addresses, phone numbers, coordinates and events are invented for the purpose of
exercising CivicOS end to end without touching anyone's real data.

They are written to look like the real thing precisely because the interesting
behaviour - redaction, coarsening, escalation - only triggers on realistic input.

- `ngo-report.txt` - a field report of the kind a small NGO produces monthly.
- `incoming-reports.jsonl` - crowd-sourced crisis reports, one JSON object per line.
